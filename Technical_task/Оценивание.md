Компиляция проекта должна быть реализована через Makefile / cmake.  Должно работать хотя бы для одной операционной системы - OSX / Linux / Windows.

Если возникает вопрос по критерию оценивания, то лучше спросить.

Любые креативные реализации могут добавить баллов лабе (даже если не все требования выполнены).

### Реализация на 4

- [ ] Нужно сделать класс графа со всей необходимой функциональностью, на оценку 4 будет достаточно только библиотеки с реализацией и ручного запуска подсчета метрик в мейне.
- [ ] Сделать 2 любых парсера
- [ ] Сделать 8 любых генераторов
- [ ] Вычислить 3 любые метрики
- [ ] Тесты на функциональность класса граф
- [ ] Тесты на метрики

### Как добить до 6

- [ ] Начиная с оценки 6 и выше нужно сделать консольное приложение с командной строкой и возможностью запускать большую часть функциональности без изменения кода. Продумать какие сценарии вообще нужно поддержать (Например метрики хочется смотреть на графах из файла, введенных вручную или сгенерированных рандомно).
- [ ] Сделать 3 любых парсера
- [ ] Сделать 12 любых генераторов (номера 10—13 точно должны быть)
- [ ] Вычислить 5 любых метрик
- [ ] Сделать оба сериализатора, для GraphViz добавить возможность показать остов и случайный цикл.
- [ ] Тесты на генераторы

### Как добить до 8

- [ ] Сделать все метрики 
- [ ] Сделать все модификации сериализаторов 
- [ ] Тесты для сериализаторов

### Как добить до 10

- [ ] В коде должна прослеживаться объектно ориентированная структура, потенциально позволяющая расширять код до бесконечности (например добавить новых метрик, добавить новых сериализаторов или генераторов)
- [ ] Добавить возможность изменить бекенд графа (внутреннюю структуру хранения)
