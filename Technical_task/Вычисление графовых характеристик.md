Для любого графа должна быть возможность вычислить любую из следующих характеристик. Для вычисления метрик должен существовать либо отдельный класс, либо в классе графа должны быть отдельные методы с кешированием результата.

- [ ] Плотность графа
- [ ] Диаметр графа
- [ ] Транзитивность графа — отношение количества треугольников к количеству триад в графе.
- [ ] Количество компонент связности
- [ ] Количество точек сочленения (dfs)
- [ ] Количество мостов (random) — через генерацию свободных переменных
- [ ] Проверка графа на двудольность (через раскраску в два цвета)
- [ ] Верхняя оценка хроматического числа ([полученная наивным жадным алгоритмом](https://ru.wikipedia.org/wiki/%D0%96%D0%B0%D0%B4%D0%BD%D0%B0%D1%8F_%D1%80%D0%B0%D1%81%D0%BA%D1%80%D0%B0%D1%81%D0%BA%D0%B0))
