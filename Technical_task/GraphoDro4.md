## Про что лаба

В лабе нужно спроектировать свой класс для работы с графами. Это должен быть не просто `using Graph = std::vector<std::vector<int>>;`. В лабе подразумевается полноценная независимая структура, поддерживающая все базовые операции работы с графами. Возможности вашего класса нужно определить самостоятельно. Вероятнее всего потребуется: добавлять ребра / вершины, проверять наличие ребра / вершины, методы обхода окрестностей, подсчета каких-нибудь свойств окрестности, объединение графов, перенумерование вершин, проверка того что вершина лист и тд. Алгоритмы тоже нужно дизайнить исходя из того как устроен класс графа.

Алгоритмы нужно делать через отдельные настраиваемые классы. Пример такого интерфейса можно подглядеть в референсах. Например, для DFS хочется реализовать классу пару виртуальных методов и переиспользовать алгоритм везде.

Вот [тут](https://www.boost.org/doc/libs/latest/libs/graph/doc/DFSVisitor.html) есть пример колбеков для DFS.

> Если правильно продумать дизайн класса, то реализовать лабу можно без боли.
